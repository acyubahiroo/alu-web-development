# HTML Advanced

![Streamly logo](images/logo.svg)

This project is the HTML structure of a video learning website called Streamly. It is written from a designer file, with pure semantic HTML only. There is no CSS yet, so the page looks plain on purpose. The styling comes in the next projects.

## What the page contains

1. **Header**: a clickable logo and three navigation links.
2. **Banner**: a title, a short text, a button and four feature blocks.
3. **Quote**: a member photo with a quote, the author and a sub-title.
4. **Videos**: four video cards, each with a thumbnail, title, text, author and a five star rating.
5. **Membership**: four plan blocks and a button.
6. **FAQ**: two rows with two questions each.
7. **Footer**: the logo, social links and a short text.

## Files

- `index.html`: the whole page.
- `images/`: placeholder images used in the page.

## How to use it

Open `index.html` in any browser. To check that the HTML is valid, paste it in the [W3C validator](https://validator.w3.org/).

## Notes

- The tags follow the structure asked in the tasks: `header`, `main` with one `section` per block, then `footer`.
- Only one `h1` is used per section, and `h2` and `h3` are used for the levels under it.
- The images are simple placeholders. They can be replaced with the real ones from the Figma file.
